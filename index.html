01 · Overview

From reactive testing to predictive quality engineering.

Traditional testing discovers failures after execution. This research project explores how AI and NLP can identify failure-prone tests before execution.

🧠

NLP-Based Intelligence

Extract useful information from test names, descriptions, textual signals, and other test-related information.

📊

Failure Prediction

Classify tests according to their predicted execution outcome and estimate their likelihood of failure.

⚡

Test Prioritization

Use predicted risk as a decision signal for intelligent regression testing and CI/CD optimization.

02 · Problem

Why predict test failures?

06 · Reproducibility

Run the experiment locally.

Clone the repository, install dependencies, generate the reproducible dataset, and train the model.

``` 
$ git clone https://github.com/upadrastaharshavardhan/AI-Based-Test-Failure-Prediction-NLP.git

$ cd AI-Based-Test-Failure-Prediction-NLP/codebase

$ pip install -r requirements.txt

$ python scripts/generate_data.py --n-samples 5000 --seed 42

$ python scripts/train.py
```
